# SOP Data Penjualan Hilang dan Gangguan POS
1. Jika data penjualan suatu toko kosong untuk satu hari atau lebih, cek pos_sync_log toko tersebut.
2. Jika status sinkronisasi FAILED, penyebabnya gangguan sistem POS, bukan penurunan penjualan. Buat tiket HIGH ke IT Support untuk sinkronisasi ulang.
3. Jangan mengambil tindakan stok atau harga berdasarkan data yang belum lengkap.
4. Beritahu Store Manager agar menyimpan bukti transaksi manual sampai data tersinkron.
